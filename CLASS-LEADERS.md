# Class leaders

Leadership assignments are admin-only user metadata, not a WordPress role.
They do not grant portal access or change a person's existing status.

## Assign or remove

1. In WordPress, open **Users → Edit User**.
2. Under **CLF class leadership**, enter **Classes led**, for example `2026, 2027`.
3. Save the user. Remove a year to end that assignment, or clear the field to remove the tag.

Use the class they lead, not necessarily their own class year. Assignments work on
any existing account, including contacts who are not students or alumni.
For a new leader-only contact, use **Users → Add New**, choose **Subscriber**
(no alumni portal access), then edit that user to assign classes.

## Find and contact

- **CLF Alumni → Members**: check **Class leaders only** and optionally enter a
  **Class led**, then click **Search**. A class-year filter also implies leaders only.
  Leader-only contacts are included in these filtered results.
- Click a person's email address to write directly using your email client.
- **Invitations & RSVPs → Manage event → Send invitations**: select **Class leaders**
  and enter a class year, or leave the year blank for all leaders.
  Inactive contacts are excluded; existing invitations are not resent.

No messages are sent just by assigning tags. No existing user is automatically
tagged or assigned a different role.

Email template branding now uses CLF / Charlotte Leadership Forum, not Alumni.
This does not rewrite historical emails, user-authored event titles or content,
or templates/settings owned by other plugins such as Gravity Forms or Gravity SMTP.
